# UX teaching figures

Editable, self-contained SVG figures accompany the original [`notes/06_ux.md`](../../../notes/06_ux.md) chapter. Place each image immediately after its corresponding explanation rather than collecting images in a separate set of notes. Source files use `viewBox`, a readable `<title>` and `<desc>`, text labels in addition to colors, and no embedded scripts or external image dependencies.

Figures illustrate possible design decisions, **not measured study results or universal laws of good design**. The 60–30–10 and golden-ratio figures are visual composition heuristics, not accessibility standards. Recheck contrast, task outcomes, responsiveness and keyboard interaction in the actual product. Edit these SVG files directly in a text editor or vector editor.
