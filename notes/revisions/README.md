## How to use this material

Read an original chapter for breadth, follow its companion for updated explanations, then run or adapt a project. When sources disagree, distinguish standards (what is specified), documentation (what a product says it supports), and empirical behavior (what you observed in a particular environment). The conceptual diagrams are editable SVGs in [`assets/diagrams`](../../assets/diagrams); source notes are in [`projects/diagrams`](../../projects/diagrams). The visual before/after wireframes are in [`assets/visual-examples`](../../assets/visual-examples) and the live example project is in [`projects/visual-examples`](../../projects/visual-examples).

**Editorial scope:** This pass reviews the introductions and representative examples in all 13 chapters. Large legacy chapters remain available and may contain additional unreviewed statements or outdated links. This is a focused correction-and-expansion pass, not a claim that every line has been exhaustively fact-checked.
