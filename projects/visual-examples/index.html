These are live browser-rendered examples, not just pictures. Change the CSS in DevTools, resize the browser, use Tab to navigate, and submit an invalid email. The “before” panels intentionally demonstrate problems and are not implementation advice. View all eight illustrated explanations.

1. Semantic HTML

Semantic elements often have the same visual appearance as generic containers. The improvement is document meaning and navigable landmarks, not an automatic style change.

Before: generic containers

<div> Main content </div>
<div> Copyright </div>

After: named landmarks

<header> and <nav>
<main> Main content
<footer> Copyright

Inspect both DOM trees and accessibility landmarks in DevTools. For a real page, use one page-level main landmark, not nested mains.
